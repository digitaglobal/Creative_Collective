# My bookings

Reservations lead the account page, with summary counts, a collapsed profile editor and links to enquiries and quotes. Upcoming includes active reservations whose end is in the future; cancelled, expired, completed and no-show reservations appear in past history even when their scheduled date is in the future. History is newest first.

Each card explains the current next step and includes venue, attendee count, Jamaica-time start/end, arrival instructions when available, totals, calendar/print actions and a link to the same space for a new booking. The link starts a fresh selection and does not submit a reservation.

Booking and change-request queries refresh every 30 seconds. Browser-local status snapshots show changes since the last visit; storage holds only booking IDs and statuses, scoped to the signed-in user. They are informational, device-specific, and optional if browser storage is blocked. Manual refresh is available. Business settings, email delivery and online payment configuration are unchanged.

Change requests retain existing server approval and pricing rules. Controls wait for change history to load before offering a new request. Pending request cards show revised price acceptance and retain the original reservation until staff approval.
