## Frontend design skills

For UI work, use the relevant project skill under `.agents/skills/`:

- Use `impeccable` for design, responsive layout, accessibility, and polish.
- Use `design-taste-frontend` for art direction and visual review.
- Use `emil-design-eng` for interaction details and motion when the task calls for them.

Treat the supplied Creative Collective design as the visual reference. Render page copy, labels, and navigation as HTML, and keep the header and footer content aligned to the same responsive side margins.

Before reporting UI work complete, visually review the rendered result in a browser at desktop and mobile widths. When a design reference is supplied, compare the rendered page directly against it and address visible differences before claiming a match. Report any remaining differences or review limitations clearly.
